# Diplom_2
Этот проект содержит автоматические API тесты для сервиса Stellar Burgers с использованием Java, RestAssured и Allure. Тесты покрывают основные сценарии работы API — регистрацию пользователей, авторизацию, создание и получение заказов.

В проекте используются
Java 11 
Maven 3.6
JUnit 4
REST Assured
Allure

Запуск тестов
mvn clean test
